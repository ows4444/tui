## Why tui

<CardGrid>
	<Card title="The Elm Architecture" icon="seti:go">
		A Model has `Init`, `Update` and `View`. `Update` returns Cmds for side
		effects; the Program runs them and feeds the results back as Msgs.
	</Card>
	<Card title="Standard library only" icon="approve-check">
		`go.mod` has no `require` directive, and a test in `internal/archtest`
		fails if any package imports outside the standard library and this module.
	</Card>
	<Card title="Cell-diff rendering" icon="rocket">
		Each frame is parsed into a grid of cells and only the cells that changed
		are written, with relative cursor movement.
	</Card>
	<Card title="Widgets that compose" icon="puzzle">
		Inputs, tables, trees, dialogs, menus, pickers, charts and more. Every
		widget has a `LayoutNode()` adapter and an accessible `Linearize` form.
	</Card>
	<Card title="Layout and theming" icon="pencil">
		Flex, grid and overlay layout nodes. 16 preset themes, component tokens,
		and glyph sets with an ASCII fallback.
	</Card>
	<Card title="Accessible by design" icon="open-book">
		`WithAccessible` switches to append-only, unstyled output for screen
		readers; reduced motion follows `NO_ANIMATION` and `REDUCE_MOTION`.
	</Card>
	<Card title="Terminal-aware" icon="laptop">
		Colour depth from the environment (honours `NO_COLOR`), an opt-in
		capability probe, bracketed paste, mouse and kitty keyboard support.
	</Card>
	<Card title="Testable" icon="list-format">
		The `tuitest` harness drives a Program headlessly. Every example checks
		its screens against golden files, which is where the screens on this
		site come from.
	</Card>
</CardGrid>

## A complete program

```go title="counter.go"
type counter struct{ n int }

func (c counter) Init() tui.Cmd { return nil }

func (c counter) Update(msg tui.Msg) (tui.Model, tui.Cmd) {
	if k, ok := msg.(tui.Key); ok && k.Type == tui.KeyRunes {
		switch k.Text {
		case "+":
			c.n++
		case "q":
			return c, tui.Quit()
		}
	}
	return c, nil
}

func (c counter) View() string { return fmt.Sprintf("count: %d", c.n) }

func main() {
	if _, err := tui.NewProgram(counter{}).Run(); err != nil {
		fmt.Println(err)
	}
}
```

The model is `ExampleNewProgram` from the repository's `example_test.go`, which
`go test` runs. [Running a Program](/program/) covers the rest.

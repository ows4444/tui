# Built with tui

Programs that use tui, so that a newcomer can see what it makes. Add yours with
a pull request: a name, one line on what it does, and a link.

## Using it today

| Program | What it does | Where |
|---|---|---|
| ACLine | A command-line tool for tracking software-delivery work (specs, tasks, decisions, the evidence a task is done), with a terminal interface. Uses `form`, `picker`, `logview`, `treeview`, `tabs`, `textinput`, `spinner` and `tuitest`. | Not yet published |
| Kaatib | A terminal app for running several coding agents on one shared task queue. In early build; built on tui through a local `replace`. | Not yet published |

## In this repository

These are small but complete tools, each with a test:

| Example | What it does |
|---|---|
| [examples/jsonview](../examples/jsonview) | Explore a JSON file or a pipe as a tree you can search. |
| [examples/diskuse](../examples/diskuse) | See what takes the space in a directory: sorted, filterable, enter to descend. |
| [examples/newproject](../examples/newproject) | Ask a few questions and write a project skeleton, with `prompt` and no Model. |
| [examples/tutorial](../examples/tutorial) and [tutorial2](../examples/tutorial2) | The task list the tutorials build. |

The other [examples](../examples) each show one idea.
